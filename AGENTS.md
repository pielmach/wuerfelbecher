# Agent Guide for Wuerfelbecher

This document provides essential context, setup steps, architecture details, and developer workflows for AI agents working on the Wuerfelbecher codebase.

## Project Overview

**Wuerfelbecher** is a lightweight Discord bot written in Python (3.14+) designed for rolling dice in tabletop role-playing games (TTRPGs).
- Supports dice with any number of sides.
- Bilingual notation support: English `d` (dice) and German `w` (Würfel) — e.g. `!r 3d20`, `!r 1w6+4`.
- Arithmetic modifier support (`+`, `-`, or summing with trailing `+`).
- In-memory roll statistics tracking (`!stats <dice_type>`).

## Setup & Environment

### Python Environment with uv

```bash
uv sync
```

### Discord Bot Token

The bot requires a Discord bot token to run. Tokens should **never** be hardcoded or committed to git.
The bot checks for tokens in the following order:
1. Docker secret file: `/run/secrets/discord_bot_token`
2. Environment variable: `DISCORD_BOT_TOKEN`

Running locally:
```bash
export DISCORD_BOT_TOKEN="<your-discord-bot-token>"
uv run python wuerfelbecher_bot.py
```

Running with Docker Compose:
```bash
echo <discord-bot-token> > discord_bot_token.secret
docker-compose up --build
```

## Development Commands

All changes must pass formatting, linting, type-checking, and tests.

### Code Formatting & Import Sorting
```bash
# Auto-format code (127 characters line length)
uv run ruff format .

# Auto-sort imports and fix lint issues
uv run ruff check --fix .
```

### Linting & Static Analysis
```bash
# Ruff linting and complexity checks (line length 127, max complexity 10)
uv run ruff check .
```

### Type Checking
```bash
# Mypy type-checking (all functions in wuerfelbecher must have type annotations)
uv run mypy wuerfelbecher/
```

### Testing & Code Coverage
```bash
# Run pytest with test coverage report
uv run pytest --cov=wuerfelbecher --cov-report=term-missing tests/
```

## Development Guidelines for Agents

- **Test-Driven Development (TDD):** Wuerfelbecher maintains 100% test coverage. Always write or update unit tests in `tests/` for any new logic, edge cases, or bug fixes.
- **Type Annotations:** All functions and methods in `wuerfelbecher/` must have complete type annotations to satisfy `mypy --disallow-untyped-defs`.
- **Formatting & Linting Standards:** Maintain `ruff` formatting with a maximum line length of 127 and clean `ruff check .` with imports sorted via Ruff's isort integration.
- **Command Handling:** Discord bot command routing and events are defined in `wuerfelbecher/bot.py`, while underlying command execution logic belongs in `wuerfelbecher/commands.py`.
- **Dice Parsing:** Any adjustments or additions to dice expression syntax should be made in `wuerfelbecher/parser.py`.
- **Security:** Do not log or expose the Discord bot token or write credentials to the repository.
